    How it works

    怎么用

    1. 写想法：一句话即可；补充时间、人力与技术约束，越具体越容易生成可验收的规格。
    2. 回答问题：澄清问题只问会改变范围的事；未回答的内容会保留为假设。
    3. 比较方案：查看 A/B 方案、讨论时间线、黑板与最终决策，确认后进入规格。
    4. 审查与导出：查看覆盖率、冲突与待确认项，确认规格后下载 Markdown / JSON。

    当前默认使用离线 Mock 智能体：流程、校验、编号与收敛判定都是真实逻辑，文案由模板生成。
