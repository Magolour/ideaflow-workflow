    How it works

    怎么用

    1. 写下想法：一句话即可，越具体越好；约束会作为讨论的固定前提。
    2. 生成文档：六个角色各自出稿，再互相批判、回应，最后由整合角色写成 11 章文档。
    3. 看结论：顶部给出共识判定与支持度；异议和未解决问题不会被抹掉。
    4. 下载：Markdown 便于继续编辑与入库；HTML 是单文件，可直接打印成 PDF。

    当前使用离线 Mock 智能体：流程、校验、编号、收敛判定都是真实逻辑，文案由模板生成。
