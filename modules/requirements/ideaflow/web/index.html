    How it works

    怎么用

    1. 选模式：设计方案产出 11 章提案；设计规格走需求快照、A/B 草案、评审、自审查与人工问题。
    2. 写下想法：一句话即可；也可以直接载入演示案例，填充后仍可修改。
    3. 看结论：提案看共识与少数意见；规格看覆盖、冲突、验收和修订记录。
    4. 下载：提案可下 Markdown / HTML；规格可下同版 Markdown 与 JSON，也可打印成 PDF。

    当前使用离线 Mock 智能体：流程、校验、编号、收敛判定都是真实逻辑，文案由模板生成。
